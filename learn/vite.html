شروع پروژه مدرن با Vite

وب و برنامه‌نویسیمتوسط۸ دقیقه

ساخت پروژه، اجرای سرور توسعه و بیلد نهایی با Vite.

Vite ابزار سریع ساخت پروژه‌های وب مدرن است؛ سرور توسعه‌اش تقریباً فوری بالا می‌آید. برای کار با آن Node.js لازم است.

ساخت پروژه

npm create vite@latest my-app
cd my-app
npm install
npm run dev

در مراحل ساخت می‌پرسد از کدام فریم‌ورک استفاده کنی: Vanilla (جاوااسکریپت ساده)، React، Vue، Svelte و غیره. برای شروع Vanilla هم کافی است.

ساختار پروژه

  • index.html نقطه شروع.
  • src/main.js کد اصلی.
  • public/ فایل‌هایی که بدون پردازش کپی می‌شوند.
  • package.json وابستگی‌ها و اسکریپت‌ها.

بیلد و انتشار

npm run build      # output goes to the dist folder
npm run preview    # preview the built site locally

محتوای پوشه dist را روی هر میزبان استاتیک (مثل GitHub Pages، Netlify یا Cloudflare Pages) بگذار. اگر سایتت زیرمسیر دارد، در vite.config.js مقدار base را تنظیم کن.

نکتهبرای متغیرهای محیطی در Vite باید نام متغیر با VITE_ شروع شود و به یاد داشته باش آن‌ها در مرورگر عمومی می‌شوند، پس اسرار را آنجا نگذار.
