نصب WSL و اوبونتو در ویندوز

نصب و آماده‌سازیمتوسط۶ دقیقه

یک محیط لینوکس واقعی را بدون ماشین مجازی و داخل ویندوز اجرا کن.

WSL (Windows Subsystem for Linux) به تو اجازه می‌دهد داخل ویندوز ۱۰ و ۱۱ ترمینال لینوکس داشته باشی. برای کار با Git، Node، Python، Docker و ابزارهای سرور خیلی کاربردی است.

نصب

  1. منوی Start را باز کن، PowerShell را جست‌وجو کن و روی آن راست‌کلیک و Run as administrator را بزن.
  2. دستور زیر را اجرا کن و بعد کامپیوتر را راه‌اندازی مجدد کن.
  3. بعد از ریستارت، اوبونتو خودش باز می‌شود و از تو نام کاربری و رمز می‌خواهد.
wsl --install

دستورهای مفید

wsl -l -v          # list installed distros and their version
wsl --update      # update WSL itself
wsl --shutdown    # stop all distros
wsl -d Ubuntu     # open a specific distro

اولین کارها در اوبونتو

sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl build-essential
git --version

فایل‌های ویندوز از مسیر /mnt/c/ در دسترس‌اند. بهتر است پروژه‌هایت را داخل پوشه home خود لینوکس نگه داری (مثلاً ~/projects) چون سرعت خواندن و نوشتن خیلی بیشتر است.

نکتهدر VS Code افزونه رسمی «WSL» را نصب کن و با دستور code . از داخل ترمینال اوبونتو پروژه را باز کن. ادیتور روی ویندوز اجرا می‌شود ولی کد روی لینوکس اجرا می‌شود.
