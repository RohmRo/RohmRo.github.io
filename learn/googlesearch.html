مهارت‌های روزمره و کارمبتدی۶ دقیقه

عملگرهای جستجو برای پیدا کردن دقیق‌تر فایل، سایت و اطلاعات.

با چند عملگر ساده، به‌جای مرور ده‌ها نتیجه، مستقیم به جواب می‌رسی.

عملگرهای مفید

"exact phrase"          match this phrase exactly
words -unwanted        exclude a word
site:example.com topic  search only inside one site
filetype:pdf topic      only PDF files
intitle:guide           word must be in page title
intext:keyword          word must be in page body
related:site.com        similar sites
A OR B                  either word
*                       wildcard inside a phrase

مثال‌ها

  • site:github.com python telegram bot
  • filetype:pdf "machine learning" tutorial
  • intitle:"cheat sheet" css grid
  • how to -wordpress "static site"

فیلتر زمان و ابزارها

در Tools می‌توانی نتایج را به یک سال یا ماه اخیر محدود کنی؛ برای مستندات تکنولوژی که زود قدیمی می‌شوند خیلی مهم است.

ارزیابی منبع

  • تاریخ مقاله را ببین.
  • به منبع اصلی و مستندات رسمی اولویت بده.
  • یک ادعا را در دو منبع مستقل تأیید کن.
  • به جستجوی تصویر معکوس برای بررسی اصالت عکس‌ها مراجعه کن.
