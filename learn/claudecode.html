نصب و شروع کار با Claude Code

نصب و آماده‌سازیمبتدی۷ دقیقه

دستیار کدنویسی Anthropic را در ترمینال نصب کن و اولین کارت را با آن انجام بده.

Claude Code ابزار کدنویسی Anthropic است که پروژه‌ات را می‌خواند، فایل‌ها را ویرایش می‌کند و دستورها را اجرا می‌کند. طبق مستندات رسمی، روش پیشنهادی نصب «Native Install» است و برای آن Node.js هم لازم نیست.

نصب

مک، لینوکس و WSL:

curl -fsSL https://claude.ai/install.sh | bash

ویندوز (PowerShell):

irm https://claude.ai/install.ps1 | iex

گزینه‌های دیگر هم وجود دارد: winget install Anthropic.ClaudeCode در ویندوز و brew install --cask claude-code در مک. بعد از نصب، یک پنجره ترمینال جدید باز کن و بررسی کن:

claude --version

اولین اجرا

cd your-project
claude

بار اول از تو می‌خواهد وارد حساب شوی. برای استفاده از آن به اشتراک Claude یا حساب Anthropic Console نیاز داری.

اولین درخواست‌های خوب

  • «ساختار این پروژه را توضیح بده و بگو هر پوشه چه کاری می‌کند.»
  • «در فایل index.html یک بخش تماس اضافه کن و استایلش را مثل بخش‌های دیگر بنویس.»
  • «تست‌ها را اجرا کن و اگر خطایی بود علتش را بگو.»
نکتهبرای جزئیات و روش‌های جدیدتر همیشه مستندات رسمی را ببین: code.claude.com/docs. روش نصب و ابزارها ممکن است با گذر زمان تغییر کنند.
احتیاطClaude Code می‌تواند فایل ویرایش و دستور اجرا کند. هر مجوزی را که می‌خواهد بخوان و قبل از تأیید مطمئن شو چه کاری قرار است انجام شود.
