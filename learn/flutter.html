نصب Flutter و ساخت اولین اپلیکیشن

نصب و آماده‌سازیمتوسط۹ دقیقه

محیط توسعه اپلیکیشن موبایل با Flutter را آماده کن و اولین برنامه را اجرا کن.

Flutter یک ابزار گوگل برای ساخت اپلیکیشن اندروید، iOS، وب و دسکتاپ با یک کد (زبان Dart) است. برای شروع اپ‌سازی گزینه محبوبی است.

نصب

  1. از flutter.dev بخش Install، راهنمای سیستم‌عامل خودت را دنبال کن و Flutter SDK را دانلود و در پوشه‌ای بدون فاصله و بدون نیاز به دسترسی ادمین باز کن.
  2. پوشه flutter/bin را به PATH اضافه کن.
  3. Android Studio را نصب کن و SDK اندروید و یک شبیه‌ساز (Emulator) را از Device Manager بساز.
  4. افزونه‌های Flutter و Dart را در VS Code یا Android Studio نصب کن.

بررسی سلامت نصب

flutter doctor

این دستور همه ایرادها را با علامت ضربدر نشان می‌دهد و راه‌حل پیشنهاد می‌کند. مشکل‌ها را یکی‌یکی رفع کن تا همه تیک سبز بخورند. مجوزهای اندروید را با flutter doctor --android-licenses تأیید کن.

اولین اپلیکیشن

flutter create my_app
cd my_app
flutter run

فایل اصلی lib/main.dart است. در حالت اجرا با کلید r در ترمینال Hot Reload می‌گیری و تغییرات بدون راه‌اندازی دوباره دیده می‌شوند.

نکتهبرای تست روی گوشی واقعی اندروید، Developer Options و USB Debugging را روشن کن و با کابل وصلش کن.
