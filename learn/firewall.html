فایروال: روشن کن و درست تنظیم کن

امنیتمتوسط۶ دقیقه

فایروال در ویندوز و لینوکس چیست و چه قاعده‌هایی ضروری است.

فایروال ترافیک شبکه را با قاعده‌هایی کنترل می‌کند. ساده‌ترین قاعده درست: «همه اتصالات ورودی بسته، فقط موارد لازم باز».

ویندوز

  • تنظیمات را باز کن و Windows Security > Firewall & network protection را ببین.
  • برای شبکه‌های Private و Public فایروال باید روشن باشد.
  • در بخش Allow an app through firewall فقط برنامه‌های مطمئن را فعال بگذار.

لینوکس با ufw

sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp     # SSH (only if you need it)
sudo ufw allow 80/tcp     # HTTP
sudo ufw allow 443/tcp    # HTTPS
sudo ufw enable
sudo ufw status verbose
احتیاطقبل از فعال‌کردن فایروال روی سرور از راه دور، حتماً پورت SSH را مجاز کن؛ وگرنه دسترسی خودت را قطع می‌کنی.

اصول

  • فقط پورت‌هایی را باز کن که سرویس‌شان را واقعاً اجرا می‌کنی.
  • پورت‌های مدیریتی (SSH، RDP) را به آی‌پی‌های مشخص محدود کن یا پشت VPN ببر.
  • خروجی‌های عجیب را در لاگ‌ها بررسی کن.
نکتهفایروال ابزار دفاعی لایه‌ای است و جایگزین به‌روزرسانی، رمز قوی و آنتی‌ویروس نیست.
