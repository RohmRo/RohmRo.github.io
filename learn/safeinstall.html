نصب امن برنامه‌ها: از کجا دانلود کنیم؟

نصب و آماده‌سازیمبتدی۵ دقیقه

چطور بدون دردسر و بدون بدافزار برنامه نصب کنیم و آن‌ها را به‌روز نگه داریم.

بیشتر آلودگی‌های کامپیوتر از نصب برنامه از منبع اشتباه شروع می‌شود. چند عادت ساده جلوی بیشتر این ماجراها را می‌گیرد.

قاعده‌های طلایی

  1. فقط از سایت رسمی خود برنامه دانلود کن. آدرس را خودت تایپ کن یا از نتیجه معتبر جست‌وجو وارد شو و آدرس را با دقت بخوان.
  2. از سایت‌های «دانلود رایگان» و نسخه‌های کرک‌شده دوری کن. این‌ها رایج‌ترین مسیر پخش بدافزار هستند و بهتر است سراغ نسخه رایگان یا متن‌باز همان ابزار بروی.
  3. حجم و نام فایل را بررسی کن؛ نصب‌کننده‌ای که اندازه‌اش عجیب است یا پسوند دوبل دارد (مثل setup.pdf.exe) را اجرا نکن.
  4. اگر سایت هش (SHA-256) منتشر کرده، بعد از دانلود تطابقش را چک کن.
  5. بعد از نصب، برنامه را به‌روز نگه دار.

نصب با Winget در ویندوز

ویندوز ۱۰ و ۱۱ ابزار winget دارد که برنامه‌ها را از منبع معتبر نصب می‌کند و دیگر لازم نیست دنبال لینک بگردی.

winget search vscode
winget install Microsoft.VisualStudioCode
winget install Git.Git
winget upgrade --all

بررسی هش فایل

# Windows PowerShell
Get-FileHash .\installer.exe -Algorithm SHA256

# macOS / Linux
shasum -a 256 installer.dmg
نکتهقبل از اجرای نصب‌کننده‌های ناشناس، با یک سرویس آنلاین بررسی ویروس مثل VirusTotal هم می‌توانی آن را چک کنی؛ البته نتیجه تمیز به معنای امن بودن صددرصدی نیست.
