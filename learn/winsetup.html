برنامه‌های ضروری بعد از نصب ویندوز

نصب و آماده‌سازیمبتدی۶ دقیقه

فهرست برنامه‌های کاربردی و تنظیمات مهم برای یک ویندوز تمیز و سریع.

بعد از نصب ویندوز یک ساعت وقت بگذار تا سیستم امن، سریع و کاربردی شود.

قدم اول: به‌روزرسانی

  • Windows Update را اجرا کن تا همه به‌روزرسانی‌ها نصب شوند.
  • درایور کارت گرافیک و چیپست را از سایت سازنده (NVIDIA، AMD یا Intel) نصب کن.

برنامه‌های پیشنهادی

  • مرورگر: Chrome، Firefox یا Edge به‌همراه افزونه بلوک تبلیغات معتبر.
  • 7-Zip: باز کردن و ساخت فایل‌های فشرده.
  • VLC: پخش تقریباً هر فرمت صدا و ویدیو.
  • VS Code و Git: برای برنامه‌نویسی.
  • PowerToys: ابزارهای مایکروسافت مثل FancyZones، تغییر نام دسته‌ای و Color Picker.
  • Everything: جست‌وجوی فوری فایل‌ها.
  • مدیر رمز عبور: Bitwarden یا KeePassXC.
  • Notepad++: ویرایشگر سبک متن.

نصب دسته‌ای با Winget

winget install 7zip.7zip
winget install VideoLAN.VLC
winget install Microsoft.VisualStudioCode
winget install Git.Git
winget install Microsoft.PowerToys
winget install voidtools.Everything

تنظیمات مهم

  • در Startup Apps برنامه‌هایی که لازم نیستند را غیرفعال کن تا بوت سریع‌تر شود.
  • Windows Defender و Firewall را روشن نگه دار.
  • نمایش پسوند فایل‌ها را در File Explorer روشن کن (View > Show > File name extensions) تا فایل‌های جعلی مثل photo.jpg.exe را تشخیص بدهی.
  • برای آیکون‌های سیستم و صفحه‌کلید فارسی/انگلیسی، میانبر Win+Space را یاد بگیر.
نکتهقبل از نصب هر برنامه، فقط از سایت رسمی یا Winget نصب کن (آموزش «نصب امن برنامه‌ها» را ببین).
