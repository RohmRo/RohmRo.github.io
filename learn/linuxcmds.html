اولین قدم‌ها با لینوکس: دستورهای ضروری

نصب و آماده‌سازیمبتدی۸ دقیقه

مدیریت فایل، نصب برنامه، مجوزها و فرآیندها در ترمینال لینوکس.

لینوکس پایه بیشتر سرورها، ابزارهای امنیت و محیط‌های توسعه است. این دستورها برای شروع کافی‌اند (در WSL یا VM هم کار می‌کنند).

فایل و پوشه

pwd                 # current folder
ls -la              # list with details and hidden files
cd ~/projects       # go to a folder
mkdir -p a/b/c      # create nested folders
cp file.txt backup/ # copy
mv old.txt new.txt  # rename or move
rm file.txt         # delete (no trash!)
cat file.txt        # print a file
less file.txt       # scroll a long file (q to quit)

جست‌وجو

grep "error" app.log          # find lines containing error
grep -rn "TODO" .              # search recursively with line numbers
find . -name "*.js"            # find files by name

نصب و به‌روزرسانی (اوبونتو و دبیان)

sudo apt update
sudo apt upgrade -y
sudo apt install htop git
sudo apt remove htop

مجوزها

ls -l script.sh
chmod +x script.sh     # make executable
./script.sh
sudo chown $USER file  # change owner

خروجی ls -l مثل -rwxr-xr-- است: سه حرف اول مجوز مالک، سه حرف بعدی گروه و سه تای آخر بقیه افراد (r خواندن، w نوشتن، x اجرا).

فرآیندها

top                # live processes (q to quit)
ps aux | grep node
kill 1234          # stop process by id
df -h              # disk space
free -h            # memory

پایپ و ریدایرکت

ls | wc -l                # count files
cat log.txt | grep error    # filter output
echo "hello" > a.txt        # write (overwrite)
echo "more" >> a.txt        # append
احتیاطدستور sudo rm -rf با مسیر اشتباه می‌تواند کل سیستم را پاک کند. قبل از Enter مسیر را دوباره بخوان و هرگز دستوری را که نمی‌فهمی از اینترنت کپی و اجرا نکن.
