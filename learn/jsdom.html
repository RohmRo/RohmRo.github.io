DOM و رویدادها: صفحه را زنده کن

وب و برنامه‌نویسیمبتدی۹ دقیقه

انتخاب عناصر، تغییر متن و استایل، افزودن عنصر و گوش دادن به کلیک و تایپ.

DOM نمایش درختی صفحه در حافظه مرورگر است. با جاوااسکریپت می‌توانی آن را بخوانی و تغییر بدهی.

انتخاب عنصر

const title = document.querySelector("h1");
const items = document.querySelectorAll(".item");
const btn = document.getElementById("save");

تغییر محتوا و استایل

title.textContent = "عنوان جدید";
title.classList.add("active");
title.style.color = "tomato";
btn.disabled = true;

رویدادها

btn.addEventListener("click", () => {
  console.log("clicked");
});

document.querySelector("input").addEventListener("input", (e) => {
  console.log(e.target.value);
});

ساختن و افزودن عنصر

const li = document.createElement("li");
li.textContent = "کار جدید";
document.querySelector("ul").appendChild(li);

مثال کامل: لیست کارها

<input id="task"><button id="add">افزودن</button>
<ul id="list"></ul>
<script>
  const input = document.getElementById("task");
  document.getElementById("add").addEventListener("click", () => {
    if (!input.value.trim()) return;
    const li = document.createElement("li");
    li.textContent = input.value;
    document.getElementById("list").appendChild(li);
    input.value = "";
  });
</script>
احتیاطبرای متنی که از کاربر می‌گیری از textContent استفاده کن نه innerHTML، وگرنه در برابر XSS آسیب‌پذیر می‌شوی.
