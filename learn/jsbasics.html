وب و برنامه‌نویسیمبتدی۱۰ دقیقه

هسته زبان جاوااسکریپت با مثال‌های کوتاه و قابل اجرا در Console.

کدهای زیر را در Console مرورگر (F12) اجرا کن و تغییرشان بده؛ بهترین راه یادگیری همین است.

متغیر و نوع داده

const name = "Roham";   // cannot be reassigned
let age = 20;           // can change
age = age + 1;

const isOnline = true;
const nothing = null;
console.log(typeof name, typeof age);

شرط و حلقه

if (age >= 18) {
  console.log("adult");
} else {
  console.log("minor");
}

for (let i = 1; i <= 3; i++) {
  console.log("step", i);
}

تابع

function add(a, b) {
  return a + b;
}
const double = (n) => n * 2;   // arrow function

console.log(add(2, 3), double(4));

آرایه و شیء

const skills = ["web", "ai", "security"];
skills.push("video");

const person = { name: "Roham", rank: 6, skills };
console.log(person.name, person["rank"]);

// useful array methods
const lengths = skills.map(s => s.length);
const long = skills.filter(s => s.length > 3);
const found = skills.find(s => s === "ai");

قاعده‌های مهم

  • به‌جای var از const و let استفاده کن.
  • برای مقایسه از === استفاده کن نه ==.
  • با console.log مقدارها را ببین؛ دیباگ بدون آن تقریباً غیرممکن است.
نکتهبرای تمرین: تابعی بنویس که آرایه‌ای از اعداد بگیرد و میانگین آن‌ها را برگرداند.
