هوش مصنوعی و پرامپتمتوسط۹ دقیقه

یک روش کار مطمئن با دستیار کدنویسی: اول برنامه، قدم‌های کوچک و کنترل تغییرات.

Claude Code قدرت زیادی دارد و درست به همین دلیل نیاز به یک روش کار منظم دارد. این الگو ساده و مؤثر است.

چرخه پیشنهادی

  1. کاوش: اول از او بخواه پروژه را بخواند و توضیح بدهد. «ساختار پروژه را خلاصه کن.»
  2. برنامه: قبل از تغییر، برنامه بخواه: «برای اضافه‌کردن X، چه فایل‌هایی را عوض می‌کنی؟ برنامه‌ات را بنویس و منتظر تأیید من باش.» حالت Plan هم برای همین کار ساخته شده.
  3. اجرای کوچک: هر بار یک کار کوچک؛ نه «کل سایت را بازنویسی کن».
  4. بررسی: تغییرات را بخوان (diff) و اجرا و آزمایشش کن.
  5. ذخیره: اگر درست بود، کامیت کن تا نقطه برگشت داشته باشی.

فایل CLAUDE.md

فایلی به نام CLAUDE.md در ریشه پروژه، دستورالعمل ثابت پروژه تو است و Claude Code در شروع هر جلسه آن را می‌خواند. دستور /init یک نمونه اولیه برایت می‌سازد. نمونه محتوا:

# Project notes
- This is a static site (HTML/CSS/JS only), RTL Persian.
- Do not add frameworks or build tools.
- Keep all styles in one <style> block, colors via CSS variables.
- Test by opening index.html in a browser.
- Commit messages: short, in English.

نکته‌های کاربردی

  • درخواست‌هایت را مشخص بنویس؛ «بهترش کن» مبهم است، «هدر را روی موبایل جمع کن» روشن.
  • اگر مسیر اشتباهی رفت، متوقفش کن و جهت درست را بگو؛ لازم نیست تا آخر ادامه دهد.
  • مجوزهای اجرای دستور را با دقت بخوان و آن‌هایی را که نمی‌فهمی تأیید نکن.
  • کارهای تکراری (مثل فرمت کد یا اجرای تست) را در CLAUDE.md بنویس تا هر بار یادآوری نکنی.
نکتهAnthropic دوره‌های رایگان هم برای شروع دارد (Claude Code 101 در academy.claude.com). مستندات رسمی در code.claude.com/docs به‌روزترین منبع هستند.
