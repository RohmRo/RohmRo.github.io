Promise و async/await را بفهم

وب و برنامه‌نویسیمتوسط۸ دقیقه

چرا جاوااسکریپت ناهمگام است و چطور کارهای هم‌زمان و پشت‌سرهم را مدیریت کنیم.

کارهایی مثل دریافت از شبکه یا خواندن فایل زمان می‌برند. جاوااسکریپت منتظرشان نمی‌ماند و بعداً نتیجه را تحویل می‌دهد؛ به این می‌گوییم ناهمگام (Asynchronous).

Promise

const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

wait(1000).then(() => console.log("one second passed"));

async/await

async function run() {
  console.log("start");
  await wait(1000);
  console.log("after 1s");
  await wait(1000);
  console.log("after 2s");
}
run();

await اجرای همان تابع را متوقف می‌کند تا Promise تمام شود، ولی بقیه صفحه قفل نمی‌شود.

هم‌زمان یا پشت‌سرهم؟

// sequential: about 2 seconds
await wait(1000);
await wait(1000);

// parallel: about 1 second
await Promise.all([wait(1000), wait(1000)]);

مدیریت خطا

try {
  const data = await riskyCall();
} catch (e) {
  console.error(e);
} finally {
  console.log("always runs");
}
نکتهوقتی چند درخواست مستقل داری از Promise.all استفاده کن؛ سرعت چند برابر می‌شود.
