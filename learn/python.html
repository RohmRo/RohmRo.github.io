نصب Python، pip و محیط مجازی

نصب و آماده‌سازیمبتدی۷ دقیقه

نصب Python روی ویندوز و مک، اجرای اولین اسکریپت و ساخت محیط مجازی.

Python یکی از آسان‌ترین زبان‌ها برای شروع است و در هوش مصنوعی، اتوماسیون و تحلیل داده خیلی کاربرد دارد.

نصب در ویندوز

از python.org/downloads دانلود کن. نحوه نصب در ویندوز در حال تغییر است: python.org حالا Python install manager را هم پیشنهاد می‌دهد (از Microsoft Store یا Winget) و نصب‌کننده سنتی هنوز در دسترس است. اگر نصب‌کننده سنتی را دیدی، حتماً گزینه Add python.exe to PATH را در همان صفحه اول تیک بزن.

نصب در مک و لینوکس

در مک می‌توانی از سایت رسمی نصب‌کننده بگیری یا از Homebrew استفاده کنی. در بیشتر توزیع‌های لینوکس Python از قبل هست و با مدیر بسته توزیع به‌روز می‌شود.

brew install python

تست نصب

python --version
pip --version

# اگر python پیدا نشد (مک و لینوکس)
python3 --version

اولین اسکریپت

# hello.py
name = input("Your name: ")
print("Hello", name)

# اجرا در ترمینال:
# python hello.py

محیط مجازی (Virtual Environment)

برای هر پروژه یک محیط جدا بساز تا کتابخانه‌های پروژه‌ها با هم قاطی نشوند:

python -m venv .venv

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate

pip install requests
pip freeze > requirements.txt
احتیاطاگر ویندوز گفت اجرای اسکریپت Activate.ps1 مجاز نیست، در PowerShell دستور Set-ExecutionPolicy -Scope CurrentUser RemoteSigned را بزن یا به‌جایش از CMD و فایل activate.bat استفاده کن.
نکتهپیام python is not recognized تقریباً همیشه یعنی Python در PATH نیست. ترمینال را ببند و دوباره باز کن؛ اگر درست نشد، نصب را با تیک PATH تکرار کن.
