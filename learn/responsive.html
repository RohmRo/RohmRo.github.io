وب و برنامه‌نویسیمتوسط۸ دقیقه

چطور سایت روی موبایل، تبلت و دسکتاپ درست دیده شود.

بیشتر بازدیدکننده‌ها با موبایل وارد می‌شوند. ریسپانسیو یعنی یک کد که روی همه اندازه‌ها خوب کار کند.

۱. تگ viewport

<meta name="viewport" content="width=device-width,initial-scale=1">

بدون این تگ موبایل صفحه را کوچک‌شده دسکتاپ نشان می‌دهد.

۲. چیدمان انعطاف‌پذیر با Grid

.grid{
  display:grid;
  gap:1rem;
  grid-template-columns:repeat(auto-fit,minmax(16rem,1fr));
}

با همین چند خط، تعداد ستون‌ها بسته به عرض صفحه خودکار تغییر می‌کند.

۳. اندازه‌های سیال

h1{ font-size:clamp(1.8rem, 5vw, 4rem); }
img{ max-width:100%; height:auto; }

۴. Media Query

@media (max-width:640px){
  .nav-links{ display:none; }
  .hero{ padding:1rem; }
}

۵. تست

  • در مرورگر Ctrl+Shift+M را بزن و اندازه‌های مختلف را امتحان کن.
  • سایت را روی یک گوشی واقعی هم باز کن؛ لمس و اسکرول را فقط آنجا می‌شود درست سنجید.
  • دکمه‌ها و لینک‌ها باید برای انگشت به اندازه کافی بزرگ باشند (حدود ۴۴ پیکسل).
نکتهاز موبایل شروع کن (Mobile First): اول استایل کوچک‌ترین صفحه را بنویس و با min-width برای صفحه‌های بزرگ‌تر گسترشش بده.
