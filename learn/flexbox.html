CSS Flexbox: چیدمان یک‌بعدی بدون سردرد

وب و برنامه‌نویسیمبتدی۸ دقیقه

مرکزچین کردن، فاصله‌گذاری و چیدمان ردیفی و ستونی با Flexbox.

Flexbox برای چیدن عناصر در یک ردیف یا یک ستون ساخته شده است. با دو ویژگی روی «والد» کنترل کامل داری.

.row{
  display:flex;
  gap:1rem;                 /* space between items */
  justify-content:space-between; /* main axis */
  align-items:center;       /* cross axis */
}

محور اصلی و محور فرعی

  • flex-direction: جهت محور اصلی؛ row (پیش‌فرض) یا column.
  • justify-content: چینش روی محور اصلی؛ flex-start، center، space-between، space-around، space-evenly.
  • align-items: چینش روی محور فرعی؛ stretch، center، flex-start، flex-end.
  • flex-wrap: اجازه رفتن به خط بعد با wrap.

رفتار فرزندها

.item{ flex:1; }        /* share free space equally */
.sidebar{ flex:0 0 16rem; } /* fixed width, no shrink */
.push{ margin-inline-start:auto; } /* push to the end */

مرکزچین کردن کامل

.center{
  display:flex;
  justify-content:center;
  align-items:center;
  min-height:100vh;
}
نکتهدر صفحه‌های راست‌به‌چپ، Flexbox خودکار جهت را برعکس می‌کند و flex-start سمت راست می‌شود.
