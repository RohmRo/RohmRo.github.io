کار با API: Postman و curl

نصب و آماده‌سازیمبتدی۷ دقیقه

درخواست HTTP بفرست، پاسخ JSON را بخوان و یاد بگیر API چطور کار می‌کند.

API یک «در» برای حرف زدن برنامه‌ها با هم است. بیشتر سرویس‌ها (آب‌وهوا، پرداخت، هوش مصنوعی، GitHub) از طریق HTTP و داده JSON کار می‌کنند.

مفاهیم

  • Method: نوع درخواست؛ GET برای خواندن، POST برای ساختن، PUT و PATCH برای ویرایش، DELETE برای حذف.
  • URL: آدرس منبع.
  • Header: اطلاعات جانبی مثل نوع داده یا کلید دسترسی.
  • Body: داده‌ای که می‌فرستی (معمولاً JSON).
  • Status code: نتیجه؛ ۲۰۰ یعنی موفق، ۴۰۴ پیدا نشد، ۴۰۱ نیاز به احراز هویت، ۵۰۰ خطای سرور.

با curl

curl https://api.github.com/users/octocat

curl -X POST https://example.com/api/items \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"test\"}"

دستور اول بدون هیچ کلیدی اطلاعات عمومی یک کاربر GitHub را برمی‌گرداند.

با Postman

  1. برنامه را از postman.com نصب کن.
  2. New و بعد HTTP Request را بزن.
  3. Method را انتخاب کن، آدرس را بنویس و Send را بزن.
  4. در پایین پاسخ JSON، Status و زمان را می‌بینی. با تب Headers و Body می‌توانی درخواست را پیچیده‌تر کنی.

خواندن API جدید

مستندات هر API معمولاً چند مثال curl دارند. ابتدا همان را کپی و اجرا کن و جواب را ببین، بعد در کد خودت بنویس.

احتیاطکلید API را در Postman یا فایل‌هایی که به اشتراک می‌گذاری فاش نکن. از متغیرهای محیطی (Environment Variables) در Postman استفاده کن.
