پرامپت‌نویسی برای کدنویسی با هوش مصنوعی

هوش مصنوعی و پرامپتمتوسط۹ دقیقه

چه اطلاعاتی را همراه درخواست کد بدهیم تا کد درست و قابل‌استفاده بگیریم.

در کدنویسی با AI، مشکل اصلی معمولاً «کم‌بودن اطلاعات» است. مدل نمی‌داند پروژه تو با چه نسخه‌ای، چه ساختاری و چه سبکی نوشته شده.

هشت چیزی که باید بگویی

  1. زبان و نسخه: مثلاً Python 3.12 یا React 18.
  2. فریم‌ورک و کتابخانه‌ها: چه چیزهایی نصب است و چه چیزی نباید اضافه شود.
  3. هدف روشن: یک جمله درباره چیزی که باید اتفاق بیفتد.
  4. کد فعلی: فقط بخش مرتبط، نه کل پروژه.
  5. رفتار فعلی و رفتار دلخواه: الان چه می‌شود و چه باید بشود.
  6. خطا: متن کامل پیام خطا.
  7. محدودیت‌ها: سبک کد، عدم تغییر فایل‌های دیگر، سازگاری با موبایل و...
  8. فرمت جواب: فقط کد؟ کد و توضیح؟ فقط تغییرات؟

قالب آماده

پرامپت نمونه
زبان و محیط: JavaScript خالص، بدون فریم‌ورک، اجرا در مرورگر هدف: وقتی کاربر روی دکمه «ارسال» می‌زند، فرم را اعتبارسنجی کن و پیام خطا را زیر هر فیلد نشان بده. کد فعلی: (اینجا کد را بچسبان) محدودیت‌ها: کتابخانه جدید اضافه نکن. نام کلاس‌های CSS موجود را تغییر نده. خروجی: فقط بخش‌هایی از کد که باید عوض شوند، با توضیح کوتاه برای هر تغییر.

عادت‌های درست

  • کوچک بخواه: یک تابع، یک باگ یا یک بخش در هر درخواست.
  • اول برنامه بخواه: «قبل از نوشتن کد، فایل‌هایی که باید عوض شوند و روش کار را لیست کن.»
  • درخواست توضیح: «هر قسمت را ساده توضیح بده تا یاد بگیرم.»
  • درخواست تست: «چند مثال یا تست برای بررسی درستی کدت بنویس.»
  • هر تغییر را اجرا کن: کد را کورکورانه کپی نکن؛ هر بار اجرا و آزمایش کن.
