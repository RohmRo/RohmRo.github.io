اجرای مدل هوش مصنوعی روی کامپیوتر خودت با Ollama

هوش مصنوعی و پرامپتمتوسط۸ دقیقه

مدل‌های متن‌باز را آفلاین و خصوصی اجرا کن و از کد صدایشان بزن.

Ollama ابزاری است که اجرای مدل‌های زبانی متن‌باز را روی کامپیوتر خودت ساده می‌کند. داده‌ها از سیستم تو بیرون نمی‌روند و بعد از دانلود مدل، اینترنت لازم نیست.

نصب و اجرا

  1. از سایت رسمی ollama.com نصب‌کننده سیستم‌عاملت را دانلود و نصب کن.
  2. در ترمینال یک مدل را اجرا کن. نام مدل‌ها تغییر می‌کند؛ فهرست به‌روز در کتابخانه ollama.com/library هست.
  3. با فرمان /bye از گفت‌وگو خارج شو.
ollama run <model-name>
ollama list
ollama pull <model-name>
ollama rm <model-name>

سخت‌افزار

  • مدل‌های کوچک (چند میلیارد پارامتر) روی بیشتر لپ‌تاپ‌ها با ۸ تا ۱۶ گیگابایت RAM اجرا می‌شوند.
  • مدل‌های بزرگ‌تر به کارت گرافیک قوی یا RAM زیاد نیاز دارند.
  • کیفیت فارسی مدل‌های کوچک محدود است؛ قبل از استفاده جدی امتحان کن.

فراخوانی از کد

Ollama به‌صورت پیش‌فرض یک API محلی روی پورت ۱۱۴۳۴ باز می‌کند:

curl http://localhost:11434/api/generate -d "{\"model\":\"<model-name>\",\"prompt\":\"Why is the sky blue?\",\"stream\":false}"
نکتهبرای پروژه‌های خصوصی (قرارداد، داده مشتری) مدل محلی یک گزینه جدی است، ولی کیفیتش را با مدل‌های بزرگ آنلاین مقایسه کن.
