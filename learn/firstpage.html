اولین صفحه وب با HTML، CSS و JavaScript

وب و برنامه‌نویسیمبتدی۱۰ دقیقه

یک صفحه کامل و تعاملی را از صفر بساز و سه نقش این سه زبان را بفهم.

هر صفحه وب از سه لایه ساخته می‌شود: HTML ساختار و محتوا، CSS ظاهر و JavaScript رفتار. یک فایل index.html بساز و کد زیر را داخلش بگذار.

<!doctype html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>اولین صفحه من</title>
  <style>
    body{font-family:system-ui,sans-serif;background:#0b0d17;color:#eee;
         display:grid;place-items:center;min-height:100vh;margin:0}
    .card{background:#1a1d2e;padding:2rem;border-radius:1rem;text-align:center}
    button{padding:.7rem 1.4rem;border:0;border-radius:999px;cursor:pointer}
  </style>
</head>
<body>
  <div class="card">
    <h1>سلام دنیا</h1>
    <p id="count">تعداد کلیک: 0</p>
    <button id="btn">کلیک کن</button>
  </div>

  <script>
    let n = 0;
    const el = document.getElementById("count");
    document.getElementById("btn").addEventListener("click", () => {
      n++;
      el.textContent = "تعداد کلیک: " + n;
    });
  </script>
</body>
</html>

اجرا

فایل را با دوبار کلیک در مرورگر باز کن یا در VS Code با افزونه Live Server روی گزینه Go Live بزن.

چه اتفاقی افتاد؟

  • تگ‌های HTML مثل h1، p و button عناصر صفحه را می‌سازند.
  • بخش style با انتخابگرها (مثل .card) ظاهر را تعیین می‌کند.
  • بخش script عنصر را با getElementById پیدا می‌کند و به کلیک گوش می‌دهد.

تمرین

  1. رنگ پس‌زمینه و دکمه را عوض کن.
  2. یک دکمه «صفر کردن» اضافه کن.
  3. تعداد کلیک را با localStorage ذخیره کن تا بعد از رفرش بماند.
