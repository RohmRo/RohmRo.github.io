نوشتن رزومه برنامه‌نویس و نمونه‌کار

مهارت‌های روزمره و کارمبتدی۸ دقیقه

ساختار رزومه یک‌صفحه‌ای، نوشتن دستاورد با عدد و چیدمان نمونه‌کارها.

قواعد کلی

  • یک صفحه برای مبتدی، حداکثر دو صفحه برای باتجربه.
  • قالب ساده، بدون عکس‌های پیچیده و ستون‌های درهم.
  • هر مورد را برای همان شغل سفارشی کن.

ساختار

  1. اطلاعات تماس: ایمیل، لینک GitHub و نمونه‌کار.
  2. خلاصه: دو یا سه خط درباره تخصص و هدف.
  3. مهارت‌ها: گروه‌بندی‌شده (زبان‌ها، فریم‌ورک‌ها، ابزارها).
  4. پروژه‌ها و تجربه: مهم‌ترین بخش.
  5. تحصیلات و دوره‌ها.

نوشتن دستاورد

فرمول: فعل اقدام + کار + نتیجه قابل‌اندازه‌گیری.

  • ضعیف: «مسئول طراحی سایت بودم.»
  • قوی: «سایت فروشگاهی را با React ساختم؛ زمان بارگذاری صفحه از ۶ ثانیه به ۲ ثانیه رسید.»

نمونه‌کار

  • ۳ تا ۵ پروژه خوب بهتر از ۲۰ پروژه نیمه‌کاره است.
  • برای هر پروژه: مسئله، راه‌حل، فناوری‌ها، لینک زنده و کد.
  • README مرتب در GitHub بنویس و تصویر یا گیف اضافه کن.
  • در پروژه‌های تیمی بگو نقش دقیق تو چه بود.
نکتهآنچه نمی‌توانی در مصاحبه توضیح بدهی، در رزومه ننویس.
