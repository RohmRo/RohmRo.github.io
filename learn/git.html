نصب Git و اولین مخزن روی GitHub

نصب و آماده‌سازیمبتدی۸ دقیقه

نسخه‌بندی کد با Git، ساخت مخزن و ارسال آن به GitHub.

Git تاریخچه تغییرات کدت را نگه می‌دارد تا هر وقت خراب شد به نسخه سالم برگردی. GitHub هم جایی است که مخزن‌هایت را آنلاین نگه می‌دارد و سایت شخصی هم می‌تواند روی آن میزبانی شود.

نصب و تنظیم اولیه

از git-scm.com نصب کن (یا winget install Git.Git). سپس یک‌بار نام و ایمیلت را تنظیم کن:

git --version
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main

اولین مخزن محلی

mkdir my-site
cd my-site
git init
# فایل index.html را بساز
git add .
git commit -m "first commit"

فرستادن به GitHub

  1. در github.com وارد حسابت شو و یک Repository خالی بساز.
  2. آدرسی که GitHub نشان می‌دهد را به پروژه وصل کن و بفرست.
git remote add origin https://github.com/USERNAME/my-site.git
git branch -M main
git push -u origin main

GitHub رمز عبور ساده را برای push قبول نمی‌کند. با نصب Git برای ویندوز ابزار Git Credential Manager هم نصب می‌شود که پنجره ورود از مرورگر را باز می‌کند؛ یا می‌توانی از Personal Access Token استفاده کنی.

چرخه کار روزمره

git status
git add .
git commit -m "describe the change"
git push
نکتهپیام کامیت را کوتاه و روشن بنویس، مثلاً «اضافه کردن بخش آموزش». اگر چند ماه بعد دنبال یک تغییر بگردی، قدر همین پیام‌ها را می‌دانی.
