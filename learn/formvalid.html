فرم‌ها و اعتبارسنجی ورودی

وب و برنامه‌نویسیمبتدی۷ دقیقه

فرم درست با HTML، اعتبارسنجی مرورگر و بررسی تکمیلی با جاوااسکریپت.

فرم با ویژگی‌های داخلی HTML

<form id="contact">
  <label for="name">نام</label>
  <input id="name" name="name" required minlength="2">

  <label for="email">ایمیل</label>
  <input id="email" name="email" type="email" required>

  <label for="msg">پیام</label>
  <textarea id="msg" name="msg" required maxlength="500"></textarea>

  <button type="submit">ارسال</button>
</form>

ویژگی‌های required، type="email"، minlength، pattern و min/max بدون یک خط جاوااسکریپت اعتبارسنجی می‌کنند.

کنترل با جاوااسکریپت

const form = document.getElementById("contact");
form.addEventListener("submit", (e) => {
  e.preventDefault();
  if (!form.checkValidity()) {
    form.reportValidity();
    return;
  }
  const data = Object.fromEntries(new FormData(form));
  console.log(data);
});

نکته‌های مهم

  • هر فیلد را با label به‌همراه for وصل کن تا هم قابل‌کلیک باشد و هم برای صفحه‌خوان قابل‌فهم.
  • نوع درست type بگذار (tel، email، number) تا کیبورد مناسب موبایل باز شود.
  • پیام خطا را کنار فیلد و به زبان ساده بنویس.
احتیاطاعتبارسنجی سمت مرورگر فقط برای راحتی کاربر است. هر ورودی باید در سمت سرور هم دوباره بررسی شود چون مهاجم می‌تواند مرورگر را دور بزند.
