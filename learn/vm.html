ساخت آزمایشگاه مجازی با VirtualBox

نصب و آماده‌سازیمتوسط۸ دقیقه

یک سیستم‌عامل جدید را بدون خطر برای کامپیوتر اصلی نصب کن و آزمایش کن.

ماشین مجازی (VM) یک کامپیوتر شبیه‌سازی‌شده داخل کامپیوتر اصلی توست. برای یادگیری لینوکس، آزمایش نرم‌افزارهای ناشناس و تمرین امنیت شبکه (روی سیستم‌های خودت) عالی است چون هر چه خراب شود فقط داخل VM می‌ماند.

نصب

  1. VirtualBox را از virtualbox.org دانلود و نصب کن.
  2. ISO سیستم‌عامل دلخواه (مثل Ubuntu Desktop) را از سایت رسمی دانلود کن.
  3. در VirtualBox دکمه New را بزن، نام و فایل ISO را بده و نوع را Linux و Ubuntu بگذار.
  4. حداقل ۴ گیگابایت RAM، ۲ هسته CPU و ۲۵ گیگابایت دیسک بده.
  5. VM را اجرا کن و مراحل نصب Ubuntu را مثل یک کامپیوتر واقعی انجام بده.

بعد از نصب

  • Guest Additions: از منوی Devices نصبش کن تا کلیپ‌بورد مشترک و رزولوشن خودکار کار کند.
  • Snapshot: قبل از هر آزمایش خطرناک یک Snapshot بگیر تا با یک کلیک به حالت قبل برگردی.
  • شبکه: حالت NAT برای اینترنت ساده کافی است؛ حالت Host-only برای آزمایش شبکه داخلی بین چند VM.

اگر VM بالا نیامد

  • در BIOS گزینه Virtualization (Intel VT-x یا AMD-V) را فعال کن.
  • در ویندوز اگر Hyper-V یا WSL فعال است ممکن است سرعت یا سازگاری تغییر کند.
احتیاطفقط روی سیستم‌ها و شبکه‌هایی که مال خودت هستند یا اجازه کتبی داری آزمایش امنیتی انجام بده.
