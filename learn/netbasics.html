مبانی شبکه: IP، DNS، پورت و ابزارهای عیب‌یابی

امنیتمتوسط۹ دقیقه

پایه‌ای که برای امنیت شبکه و کار با سرور باید بدانی، همراه دستورهای واقعی.

فهمیدن شبکه، پایه همه کارهای امنیتی است. این مفاهیم را یک‌بار خوب یاد بگیر.

مفاهیم

  • آی‌پی (IP): آدرس دستگاه در شبکه؛ IPv4 مثل 192.168.1.10 و IPv6.
  • شبکه خصوصی و عمومی: آدرس‌های 192.168.x.x، 10.x.x.x و 172.16-31.x.x فقط داخل شبکه خانگی معنی دارند.
  • DNS: مثل دفترچه تلفن؛ نام دامنه را به آی‌پی تبدیل می‌کند.
  • پورت: شماره سرویس روی یک دستگاه؛ HTTP ۸۰، HTTPS ۴۴۳، SSH ۲۲.
  • TCP و UDP: TCP اتصال مطمئن و مرتب (وب)، UDP سریع‌تر و بدون تضمین (تماس تصویری).
  • Gateway: دروازه‌ای که ترافیک را به بیرون می‌برد (روتر).

دستورهای عیب‌یابی

ping 8.8.8.8             # is the internet reachable?
ping example.com         # does DNS work?
nslookup example.com     # DNS lookup
tracert example.com      # Windows: path to the server
traceroute example.com   # macOS / Linux
ipconfig /all            # Windows: your IP, gateway, DNS
ip a                     # Linux: your addresses
netstat -an              # open connections and ports

یک عیب‌یابی نمونه: «اینترنت ندارم»

  1. ping 8.8.8.8 جواب می‌دهد؟ اگر نه، مشکل اتصال یا روتر است.
  2. اگر آی‌پی جواب داد ولی ping example.com نه، مشکل DNS است؛ DNS را عوض کن یا روتر را ریستارت کن.
  3. بقیه دستگاه‌ها هم مشکل دارند؟ پس مشکل از روتر یا ارائه‌دهنده است.
نکتهبرای یادگیری عملی، ابزار Wireshark روی ترافیک خودت نشان می‌دهد پشت یک درخواست ساده وب چقدر بسته رد و بدل می‌شود.
