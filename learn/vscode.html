نصب VS Code و افزونه‌های ضروری

نصب و آماده‌سازیمبتدی۶ دقیقه

محبوب‌ترین ویرایشگر کد را نصب و برای کار روزمره تنظیم کن.

Visual Studio Code (به‌اختصار VS Code) ویرایشگر رایگان مایکروسافت است و برای وب، Python، Node و تقریباً هر زبان دیگری مناسب است.

نصب

  1. به سایت رسمی code.visualstudio.com برو و نسخه مناسب سیستم‌عاملت را دانلود کن.
  2. در ویندوز نصب‌کننده را اجرا کن. در مرحله Select Additional Tasks تیک‌های Add to PATH و Add Open with Code را روشن بگذار.
  3. برنامه را باز کن و از منوی File گزینه Open Folder را بزن تا پوشه پروژه‌ات را باز کنی.

افزونه‌های پیشنهادی

کلیدهای Ctrl+Shift+X پنل افزونه‌ها را باز می‌کند. این‌ها برای شروع کافی‌اند:

  • Live Server: صفحه HTML را با ذخیره هر تغییر خودکار در مرورگر نشان می‌دهد.
  • Prettier: کد را مرتب و یکدست می‌کند.
  • ESLint: خطاهای جاوااسکریپت را زیر کد نشان می‌دهد.
  • Python (از خود Microsoft): پشتیبانی کامل Python.
  • GitLens: تاریخچه Git را کنار هر خط نشان می‌دهد.
  • Error Lens: پیام خطا را کنار همان خط نمایش می‌دهد.

تنظیمات مفید

کلیدهای Ctrl+کاما تنظیمات را باز می‌کنند. دو گزینه را جست‌وجو و روشن کن:

  • Format On Save تا هر بار ذخیره، کد خودکار مرتب شود.
  • Auto Save با مقدار afterDelay تا فراموش نکنی ذخیره کنی.
نکتهبرای متن‌های فارسی داخل فایل‌ها یا README، از فونتی استفاده کن که فارسی را خوب نشان بدهد و ذخیره فایل‌ها را روی UTF-8 نگه دار (پایین‌ترین نوار VS Code رمزگذاری را نشان می‌دهد).
