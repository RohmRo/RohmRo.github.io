انیمیشن در CSS: transition و keyframes

وب و برنامه‌نویسیمتوسط۸ دقیقه

افکت هاور، ظاهر شدن نرم و انیمیشن تکرارشونده، بدون جاوااسکریپت.

Transition: تغییر نرم

.btn{
  background:#2b6cff;
  transform:translateY(0);
  transition:transform .25s ease, background .25s ease;
}
.btn:hover{
  background:#4d86ff;
  transform:translateY(-3px);
}

هر وقت ویژگی تغییر کند (مثلاً با hover)، CSS آن را در مدت مشخص‌شده نرم می‌کند.

Keyframes: انیمیشن چندمرحله‌ای

@keyframes fadeUp{
  from{ opacity:0; transform:translateY(20px); }
  to{ opacity:1; transform:none; }
}
.card{
  animation:fadeUp .6s ease both;
}

@keyframes pulse{
  50%{ opacity:.4; }
}
.dot{ animation:pulse 2s infinite; }

قاعده‌های کارایی

  • فقط transform و opacity را انیمیت کن؛ این دو روی GPU اجرا می‌شوند و روان‌اند.
  • از انیمیت کردن width، height، top و left پرهیز کن چون چیدمان صفحه را دوباره محاسبه می‌کنند.
  • زمان‌ها را بین ۱۵۰ تا ۶۰۰ میلی‌ثانیه نگه دار.

احترام به کاربر

@media (prefers-reduced-motion: reduce){
  *{ animation:none !important; transition:none !important; }
}
نکتهکاربرانی که از سیستم‌عامل خود حرکت کمتر خواسته‌اند را با این Media Query رعایت کن؛ هم دسترس‌پذیری است و هم حرفه‌ای‌گری.
