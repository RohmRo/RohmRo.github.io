انتشار سایت روی GitHub Pages

وب و برنامه‌نویسیمبتدی۸ دقیقه

سایتت را رایگان و با آدرس username.github.io آنلاین کن.

GitHub Pages سایت‌های استاتیک (HTML، CSS و JavaScript) را رایگان میزبانی می‌کند. سایت شخصی rohmro.github.io هم به همین روش منتشر شده است.

مراحل

  1. در GitHub یک مخزن جدید بساز. برای سایت شخصی نام مخزن باید دقیقاً USERNAME.github.io باشد.
  2. فایل index.html را در ریشه مخزن بگذار (با دکمه Add file یا با Git).
  3. در مخزن به Settings و بعد Pages برو.
  4. در بخش Source گزینه Deploy from a branch را انتخاب کن، شاخه main و پوشه / (root) را بزن و ذخیره کن.
  5. بعد از یکی دو دقیقه سایت روی آدرس https://USERNAME.github.io آنلاین می‌شود.

به‌روزرسانی سایت

git add .
git commit -m "update site"
git push

هر push به شاخه main سایت را دوباره منتشر می‌کند.

مشکلات رایج

  • سایت ۴۰۴ می‌دهد: نام فایل باید دقیقاً index.html و با حروف کوچک باشد.
  • تغییرات دیده نمی‌شود: چند دقیقه صبر کن و با Ctrl+F5 رفرش کامل بزن.
  • عکس‌ها نمی‌آیند: مسیرها را نسبی بنویس (مثل assets/img/a.jpg) و به حروف بزرگ و کوچک دقت کن.
نکتهبرای دامنه اختصاصی در همان صفحه Pages می‌توانی Custom domain را وارد کنی؛ البته باید رکوردهای DNS دامنه را هم تنظیم کنی.
