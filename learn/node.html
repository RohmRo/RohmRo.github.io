نصب Node.js و npm

نصب و آماده‌سازیمبتدی۶ دقیقه

محیط جاوااسکریپت خارج از مرورگر را آماده کن و اولین پروژه npm را بساز.

Node.js جاوااسکریپت را بیرون از مرورگر اجرا می‌کند. با آن سرور می‌سازی، ابزارهای ساخت (مثل Vite) را اجرا می‌کنی و بسته‌های هزاران‌تایی npm را نصب می‌کنی.

نصب

  1. به nodejs.org برو و نسخه LTS را دانلود کن (نسخه پایدار و مناسب کار روزمره).
  2. نصب‌کننده را با گزینه‌های پیش‌فرض اجرا کن.
  3. ترمینال را باز کن و نصب را بررسی کن.
node -v
npm -v

اولین پروژه

mkdir my-app
cd my-app
npm init -y
npm install express

حالا فایلی با نام server.js بساز:

const express = require("express");
const app = express();

app.get("/", (req, res) => {
  res.send("Hello from Node!");
});

app.listen(3000, () => console.log("http://localhost:3000"));
node server.js

حالا آدرس http://localhost:3000 را در مرورگر باز کن.

دستورهای npm که زیاد لازم می‌شوند

  • npm install همه وابستگی‌های فایل package.json را نصب می‌کند.
  • npm install نام-بسته یک بسته جدید اضافه می‌کند.
  • npm run dev یا npm start اسکریپت‌های تعریف‌شده در package.json را اجرا می‌کنند.
  • npx نام-ابزار یک ابزار را بدون نصب دائمی اجرا می‌کند.
نکتهپوشه node_modules را هرگز در Git قرار نده؛ آن را در فایل .gitignore بنویس.
