خروجی ساخت‌یافته (JSON) از مدل بگیر

هوش مصنوعی و پرامپتمتوسط۷ دقیقه

چطور از AI داده قابل پردازش بگیری و خطاهای قالب را کنترل کنی.

وقتی خروجی AI قرار است وارد برنامه‌ات شود، باید قالبش قابل پیش‌بینی باشد. JSON رایج‌ترین انتخاب است.

پرامپت

پرامپت نمونه
از متن زیر اطلاعات را استخراج کن و فقط یک JSON معتبر برگردان، بدون توضیح اضافه و بدون بلوک کد. کلیدها دقیقاً این‌ها باشند: name (رشته)، phone (رشته یا null)، city (رشته یا null)، interested_in (آرایه‌ای از رشته‌ها). اگر مقداری در متن نبود null بگذار و حدس نزن. متن: (متن)

پردازش در کد

function parseModelJson(text) {
  // remove accidental code fences
  const clean = text.replace(/^```(?:json)?|```$/g, "").trim();
  try {
    return JSON.parse(clean);
  } catch (e) {
    return null; // ask the model again or fall back
  }
}

قواعد

  • همیشه خروجی را با JSON.parse امتحان کن و حالت شکست را مدیریت کن.
  • فیلدها و نوع‌ها را بعد از پارس هم بررسی کن (مثلاً با یک کتابخانه اعتبارسنجی).
  • بسیاری از APIها قابلیت «خروجی ساخت‌یافته» یا «JSON mode» دارند که تضمین قوی‌تری می‌دهد؛ در مستندات سرویس خودت دنبالش بگرد.
  • برای وقتی فرمت خراب است، یک بار دوباره بپرس و خطای دقیق را بده.
