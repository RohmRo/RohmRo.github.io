نصب Docker و اجرای اولین کانتینر

نصب و آماده‌سازیمتوسط۸ دقیقه

کانتینر چیست، Docker را نصب کن و یک برنامه را در محیط ایزوله اجرا کن.

Docker برنامه را همراه با همه وابستگی‌هایش در یک «کانتینر» بسته‌بندی می‌کند. نتیجه این است که برنامه روی لپ‌تاپ تو، سرور و کامپیوتر همکارت دقیقاً یکسان اجرا می‌شود.

نصب

  • ویندوز و مک: Docker Desktop را از سایت رسمی docker.com دانلود و نصب کن. در ویندوز از WSL 2 استفاده می‌کند.
  • لینوکس: طبق راهنمای رسمی Docker Engine برای توزیع خودت نصب کن.
  • برای استفاده شخصی و آموزشی Docker Desktop معمولاً رایگان است؛ قوانین مجوز برای شرکت‌های بزرگ متفاوت است.

تست نصب

docker --version
docker run hello-world

دستورهای پایه

docker ps                 # running containers
docker ps -a              # all containers
docker images             # downloaded images
docker stop <id>          # stop a container
docker rm <id>            # remove a container
docker run -d -p 8080:80 nginx   # run nginx in background on port 8080

بعد از اجرای دستور آخر، آدرس http://localhost:8080 را باز کن؛ صفحه خوش‌آمد nginx را می‌بینی.

یک Dockerfile ساده برای Node

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]
docker build -t my-app .
docker run -p 3000:3000 my-app
نکتهفایل .dockerignore بساز و node_modules و .env را داخلش بنویس تا داخل image نروند.
