ترمینال برای مبتدی‌ها: دستورهای پایه

نصب و آماده‌سازیمبتدی۶ دقیقه

ترمینال چیست، چطور بازش کنیم و ده دستوری که هر روز لازم می‌شود.

ترمینال (Terminal یا Command Line) جایی است که با تایپ دستور به کامپیوتر فرمان می‌دهی. تقریباً همه ابزارهای برنامه‌نویسی، از Git و Python تا Claude Code، از آن استفاده می‌کنند؛ پس بهتر است از همان اول باهاش راحت شوی.

باز کردن ترمینال

  • ویندوز: کلید Win را بزن و Terminal یا PowerShell را جست‌وجو کن.
  • مک: کلیدهای Cmd+Space و تایپ Terminal.
  • لینوکس: در بیشتر توزیع‌ها Ctrl+Alt+T.
  • داخل VS Code: کلیدهای Ctrl+بک‌تیک (کلید بالای Tab).

دستورهای پایه

  • pwd مسیر پوشه‌ای که الان داخلش هستی را نشان می‌دهد.
  • ls (در CMD ویندوز dir) فایل‌ها و پوشه‌ها را لیست می‌کند.
  • cd نام-پوشه وارد یک پوشه می‌شود و cd .. یک پوشه به عقب برمی‌گردد.
  • mkdir نام پوشه جدید می‌سازد.
  • cat فایل (در CMD type) محتوای یک فایل متنی را نشان می‌دهد.
  • cp و mv کپی و جابه‌جایی یا تغییر نام فایل (در CMD: copy و move).
  • clear (در CMD cls) صفحه را پاک می‌کند.
mkdir my-project
cd my-project
ls
pwd

سه ترفند که کلی وقت صرفه‌جویی می‌کند

  1. کلید Tab نام فایل و پوشه را خودکار کامل می‌کند.
  2. کلید فلش بالا دستورهای قبلی را برمی‌گرداند.
  3. کلیدهای Ctrl+C هر برنامه‌ای که در حال اجراست را متوقف می‌کنند.
احتیاطدستورهای حذف مثل rm -rf در لینوکس و مک یا del در ویندوز برگشت‌پذیر نیستند. قبل از اجرا مسیر را دوباره بخوان.
