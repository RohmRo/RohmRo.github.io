بهینه‌سازی سرعت سایت (Core Web Vitals)

وب و برنامه‌نویسیمتوسط۹ دقیقه

مهم‌ترین کارها برای سریع کردن سایت و بهتر شدن تجربه کاربر و سئو.

سایت کند، بازدیدکننده و رتبه گوگل را از دست می‌دهد. گوگل سه معیار اصلی «Core Web Vitals» را می‌سنجد:

  • LCP: سرعت نمایش بزرگ‌ترین بخش صفحه (هدف: زیر ۲٫۵ ثانیه).
  • INP: سرعت پاسخ صفحه به تعامل کاربر (هدف: زیر ۲۰۰ میلی‌ثانیه).
  • CLS: میزان پرش ناگهانی چیدمان (هدف: زیر ۰٫۱).

تصاویر، مهم‌ترین عامل

  • قبل از آپلود فشرده کن و از WebP یا AVIF استفاده کن.
  • اندازه واقعی بگذار؛ عکس ۴۰۰۰ پیکسلی برای کادر ۴۰۰ پیکسلی هدر دادن است.
  • loading="lazy" برای تصاویر پایین صفحه.
  • width و height را روی img بنویس تا چیدمان نپرد (CLS).
<img src="hero.webp" width="1200" height="630" alt="..." fetchpriority="high">
<img src="gallery-1.webp" width="600" height="400" alt="..." loading="lazy">

اسکریپت و CSS

  • اسکریپت‌های غیرضروری را با defer بارگذاری کن.
  • کتابخانه‌های سنگین را فقط وقتی لازم است لود کن.
  • CSS و JS را در بیلد نهایی فشرده (Minify) کن.

فونت

از font-display: swap استفاده کن و فقط وزن‌هایی که واقعاً لازم است را بگیر؛ هر وزن اضافه یک فایل است.

اندازه‌گیری

  1. در Chrome صفحه را با F12 باز کن و تب Lighthouse را اجرا کن.
  2. پیشنهادهای قرمز و نارنجی را به ترتیب اثر حل کن.
  3. دوباره بسنج؛ همیشه روی حالت موبایل هم تست کن.
نکتهمعمولاً فقط حل مشکل تصاویر، بیشتر از نیمی از امتیاز سرعت را درست می‌کند.
