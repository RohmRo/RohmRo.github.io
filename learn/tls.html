HTTPS و گواهی‌های TLS: قفل مرورگر یعنی چه؟

امنیتمتوسط۷ دقیقه

چطور HTTPS کار می‌کند، Let's Encrypt و خطاهای رایج گواهی.

HTTPS یعنی ارتباط بین مرورگر و سرور با TLS رمزگذاری شده است. هر کسی بین شما (وای‌فای، ارائه‌دهنده) فقط داده بی‌معنی می‌بیند.

قفل مرورگر چه می‌گوید؟

  • ارتباط رمزگذاری شده است.
  • گواهی را یک مرجع معتبر برای همان دامنه صادر کرده است.
  • نمی‌گوید خود سایت قابل‌اعتماد است؛ سایت‌های فیشینگ هم می‌توانند گواهی بگیرند.

دریافت گواهی رایگان

Let's Encrypt گواهی رایگان صادر می‌کند. بسیاری از میزبان‌ها (GitHub Pages، Netlify، Cloudflare) آن را خودکار فعال می‌کنند. در سرور شخصی از ابزار Certbot استفاده می‌شود.

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d example.com -d www.example.com

خطاهای رایج

  • گواهی منقضی‌شده: تمدید خودکار را فعال کن.
  • عدم تطبیق نام دامنه: گواهی برای دامنه دیگری صادر شده.
  • Mixed Content: صفحه HTTPS منابع HTTP بارگذاری می‌کند؛ همه آدرس‌ها را به HTTPS تغییر بده.
  • ساعت سیستم اشتباه باعث خطای گواهی می‌شود.

تقویت

  • تمام ترافیک HTTP را به HTTPS ریدایرکت کن.
  • هدر HSTS را بعد از اطمینان فعال کن تا مرورگر همیشه HTTPS بخواهد.
احتیاطاگر مرورگر هشدار گواهی نشان داد، برای سایت‌های حساس (بانک، ایمیل) هرگز «ادامه بده» را نزن.
