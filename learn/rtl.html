فارسی و راست‌به‌چپ در وب

وب و برنامه‌نویسیمتوسط۷ دقیقه

جهت متن، فونت، اعداد و خطاهای رایج صفحه‌های فارسی.

یک سایت فارسی خوب فقط ترجمه متن نیست؛ جهت چیدمان، فونت و جزئیات ریز هم مهم است.

۱. جهت و زبان صفحه

<html lang="fa" dir="rtl">

با همین یک خط، متن‌ها راست‌چین می‌شوند، ستون‌ها از راست شروع می‌شوند و صفحه‌خوان‌ها زبان را درست تشخیص می‌دهند.

۲. فونت فارسی

فونت‌هایی مثل Vazirmatn، Estedad و Sahel از Google Fonts یا مخازن متن‌باز قابل استفاده‌اند.

<link href="https://fonts.googleapis.com/css2?family=Vazirmatn:wght@400;700&display=swap" rel="stylesheet">

<style>
  body { font-family: "Vazirmatn", system-ui, sans-serif; }
</style>

۳. ویژگی‌های منطقی CSS

به‌جای left و right از ویژگی‌های «منطقی» استفاده کن تا هم در RTL و هم در LTR درست کار کنند:

margin-inline-start: 1rem;   /* به‌جای margin-right در RTL */
padding-inline: 1.5rem;
text-align: start;
inset-inline: 0;

۴. متن‌های مخلوط

وقتی کلمه انگلیسی، شماره یا آدرس وسط جمله فارسی می‌آید، ممکن است علامت‌ها جابه‌جا دیده شوند. برای آن بخش‌ها از dir="ltr" یا تگ bdi استفاده کن.

<p>آدرس: <bdi dir="ltr">info@example.com</bdi></p>

۵. اعداد

اگر اعداد فارسی (۱۲۳) می‌خواهی، هم می‌توانی خودت بنویسی و هم با toLocaleString("fa-IR") در جاوااسکریپت تبدیل کنی.

(12345).toLocaleString("fa-IR")  // ۱۲٬۳۴۵
نکتهکد و دستورها همیشه باید LTR بمانند. برای بلوک‌های کد direction:ltr; text-align:left بگذار.
