Fetch API: گرفتن داده از اینترنت در جاوااسکریپت

وب و برنامه‌نویسیمتوسط۸ دقیقه

درخواست GET و POST، خواندن JSON و مدیریت خطا با async/await.

fetch درخواست HTTP می‌فرستد و Promise برمی‌گرداند. با async/await کدش مثل کد معمولی خوانا می‌شود.

GET

async function loadUser(name) {
  try {
    const res = await fetch("https://api.github.com/users/" + name);
    if (!res.ok) throw new Error("HTTP " + res.status);
    const data = await res.json();
    console.log(data.name, data.public_repos);
  } catch (err) {
    console.error("failed:", err.message);
  }
}
loadUser("octocat");

POST با JSON

const res = await fetch("/api/messages", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: "hello" })
});
const result = await res.json();

نکته‌ها

  • fetch فقط برای خطای شبکه خطا می‌دهد؛ برای کد ۴۰۴ یا ۵۰۰ باید خودت res.ok را بررسی کنی.
  • قبل از نمایش داده، حالت «در حال بارگذاری» و «خطا» را هم در رابط در نظر بگیر.
  • اگر خطای CORS دیدی، سرور مقصد اجازه درخواست از دامنه تو را نداده؛ برای API‌های خصوصی از یک بک‌اند واسط استفاده کن.
احتیاطکلید API را در fetch داخل کد سمت مرورگر نگذار؛ هر بازدیدکننده‌ای می‌تواند آن را ببیند.
