نصب FFmpeg و کارهای روزمره با آن

نصب و آماده‌سازیمتوسط۷ دقیقه

تبدیل، برش، فشرده‌سازی و استخراج صدا از ویدیو با چند دستور.

FFmpeg ابزار خط فرمان رایگان برای کار با ویدیو و صداست و پشت‌صحنه بسیاری از برنامه‌های ویرایش همین است. بعد از چند دستور، خیلی از کارها را بدون باز کردن نرم‌افزار سنگین انجام می‌دهی.

نصب

# Windows
winget install Gyan.FFmpeg

# macOS
brew install ffmpeg

# Ubuntu / WSL
sudo apt install -y ffmpeg

بعد از نصب، ترمینال را ببند و دوباره باز کن و با ffmpeg -version بررسی کن.

دستورهای پرکاربرد

# convert any video to MP4 (H.264 + AAC)
ffmpeg -i input.mov -c:v libx264 -crf 20 -c:a aac output.mp4

# cut from 00:00:10 to 00:00:25 without re-encoding
ffmpeg -ss 00:00:10 -to 00:00:25 -i input.mp4 -c copy clip.mp4

# extract audio as MP3
ffmpeg -i input.mp4 -vn -codec:a libmp3lame -q:a 2 audio.mp3

# resize to 1280 pixels wide (height auto, even number)
ffmpeg -i input.mp4 -vf scale=1280:-2 small.mp4

# make a GIF from a short clip
ffmpeg -i clip.mp4 -vf "fps=12,scale=480:-1" clip.gif
  • -i فایل ورودی را مشخص می‌کند.
  • -crf کیفیت را تعیین می‌کند؛ عدد کمتر یعنی کیفیت بیشتر و حجم بیشتر.
  • -c copy بدون رمزگذاری دوباره فقط برش می‌دهد و خیلی سریع است، ولی برش روی فریم کلیدی دقیق نیست.
نکتهمسیر فایل‌هایی که فاصله دارند را داخل کوتیشن بگذار: ffmpeg -i "my video.mp4" out.mp4.
