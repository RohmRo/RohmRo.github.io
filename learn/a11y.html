دسترس‌پذیری وب (Accessibility) برای همه

وب و برنامه‌نویسیمتوسط۷ دقیقه

چک‌لیست ساده تا سایتت برای کاربران نابینا، کم‌بینا و کیبورد‌محور هم قابل‌استفاده باشد.

دسترس‌پذیری یعنی سایت برای همه قابل استفاده باشد، از جمله کسی که با کیبورد کار می‌کند، صفحه‌خوان استفاده می‌کند یا بینایی ضعیف دارد. رعایتش به سئو هم کمک می‌کند.

چک‌لیست سریع

  1. متن جایگزین: هر تصویر معنادار alt توصیفی دارد؛ تصاویر تزئینی alt="".
  2. کنتراست: نسبت روشنایی متن به پس‌زمینه حداقل ۴٫۵ به ۱ برای متن معمولی (راهنمای WCAG).
  3. کیبورد: همه چیز با Tab، Shift+Tab، Enter و Space قابل استفاده باشد و فوکوس دیده شود.
  4. ساختار: تیترها به ترتیب و بدون پرش، لندمارک‌های main و nav.
  5. فرم‌ها: هر فیلد label دارد.
  6. زبان: lang="fa" روی html.
  7. حرکت: prefers-reduced-motion را رعایت کن.
  8. اندازه لمسی: دکمه‌ها حدود ۴۴ پیکسل.

ARIA فقط وقتی لازم است

اول تگ درست HTML را بگذار (مثلاً button). فقط وقتی تگ معنادار کافی نیست از aria-label، aria-expanded و مانند آن استفاده کن.

<button aria-label="بستن منو" aria-expanded="false">✕</button>

تست

  • با Tab در کل صفحه بگرد.
  • ابزار Lighthouse مرورگر بخش Accessibility را اجرا کن.
  • صفحه را با بزرگ‌نمایی ۲۰۰٪ ببین.
نکتههیچ‌وقت outline:none را بدون جایگزین نگذار؛ کاربران کیبورد دیگر نمی‌دانند کجا هستند.
