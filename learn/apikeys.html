هوش مصنوعی و پرامپتمبتدی۶ دقیقه

کلید را کجا نگه دار، چطور دسترسی و هزینه را محدود کن و اگر لو رفت چه کار کنی.

کلید API مثل رمز عبور حساب مالی توست. هر کسی آن را داشته باشد می‌تواند به حساب تو درخواست بزند و هزینه ایجاد کند.

قواعد

  1. کلید را فقط در متغیر محیطی یا سیستم Secret بک‌اند نگه دار (مثل .env یا Secretهای Cloudflare و GitHub).
  2. فایل .env را در .gitignore بگذار.
  3. برای هر پروژه یک کلید جدا بساز تا اگر لو رفت فقط همان را باطل کنی.
  4. دسترسی کلید را به کمترین حد لازم محدود کن (فقط یک مخزن، فقط خواندن و...).
  5. در پنل سرویس سقف هزینه ماهانه و هشدار مصرف تنظیم کن.
  6. کلیدها را به‌صورت دوره‌ای عوض کن.

اگر کلیدی لو رفت

  1. فوراً در پنل سرویس کلید را باطل (Revoke) کن.
  2. کلید جدید بساز و در محل‌های درست جایگزین کن.
  3. مصرف و صورت‌حساب را بررسی کن.
  4. اگر در Git کامیت شده بود، فقط حذف از فایل کافی نیست؛ تاریخچه را هم بررسی کن و کلید قدیمی را غیرفعال بدان.

خطاهای رایج

  • گذاشتن کلید در جاوااسکریپت سمت مرورگر.
  • ارسال کلید در گفت‌وگوی AI، اسکرین‌شات یا پیام‌رسان.
  • استفاده از یک کلید برای همه پروژه‌ها.
احتیاطربات‌های خودکار مخازن عمومی GitHub را برای کلید جست‌وجو می‌کنند و گاهی ظرف چند دقیقه از کلید لو رفته سوءاستفاده می‌شود.
