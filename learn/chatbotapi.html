ساخت چت‌بات با API مدل زبانی

هوش مصنوعی و پرامپتمتوسط۱۰ دقیقه

معماری درست: صفحه وب، بک‌اند واسط، کلید مخفی و ارسال تاریخچه گفت‌وگو.

برای ساخت یک چت‌بات واقعاً هوشمند، یک مدل زبانی از طریق API صدا می‌زنی. قانون اول: کلید API هرگز در کد صفحه نباشد.

معماری

  1. صفحه وب پیام کاربر را به آدرس بک‌اند خودت می‌فرستد.
  2. بک‌اند واسط (مثلاً Cloudflare Worker یا یک سرور Node) کلید را از متغیر محیطی می‌خواند و درخواست را به API مدل می‌فرستد.
  3. پاسخ به صفحه برمی‌گردد و نمایش داده می‌شود.

نمونه درخواست به API

روش کلی در بیشتر سرویس‌ها مشابه است. مثال با Messages API شرکت Anthropic (نام مدل را از مستندات به‌روز بردار):

const r = await fetch("https://api.anthropic.com/v1/messages", {
  method: "POST",
  headers: {
    "content-type": "application/json",
    "x-api-key": process.env.API_KEY,
    "anthropic-version": "2023-06-01"
  },
  body: JSON.stringify({
    model: "claude-haiku-5-5",
    max_tokens: 800,
    system: "You are a helpful Persian assistant.",
    messages: [{ role: "user", content: "سلام" }]
  })
});
const data = await r.json();
console.log(data.content[0].text);

سمت صفحه

async function ask(history) {
  const res = await fetch("https://your-worker.example.workers.dev", {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({ messages: history })
  });
  const data = await res.json();
  return data.reply;
}

نکته‌های مهم

  • تاریخچه: مدل حافظه ندارد؛ هر بار آخرین پیام‌ها را دوباره بفرست و آن را کوتاه نگه دار.
  • محدودیت: تعداد درخواست در دقیقه و طول پیام را محدود کن تا هزینه بالا نرود.
  • CORS: فقط دامنه سایت خودت را مجاز کن.
  • هزینه: سقف مصرف ماهانه در پنل سرویس تنظیم کن.
  • System Prompt اطلاعات کسب‌وکارت را بدهد تا دقیق جواب بدهد.
نکتههمین سایت یک نمونه Worker آماده (فایل worker.js) دارد که می‌توانی در Cloudflare مستقر کنی و آدرسش را در چت‌بات سایت وارد کنی.
