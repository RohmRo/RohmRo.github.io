CSS Grid: چیدمان دوبعدی صفحه

وب و برنامه‌نویسیمتوسط۸ دقیقه

ساخت شبکه کارت‌ها و چیدمان صفحه با Grid، از ساده تا ریسپانسیو.

Grid برای وقتی است که هم ردیف و هم ستون داری؛ مثل گالری، داشبورد یا کل صفحه.

شبکه ساده

.grid{
  display:grid;
  grid-template-columns:repeat(3, 1fr); /* three equal columns */
  gap:1.5rem;
}

واحد fr یعنی «یک سهم از فضای خالی».

ریسپانسیو بدون Media Query

.cards{
  display:grid;
  gap:1rem;
  grid-template-columns:repeat(auto-fit, minmax(16rem, 1fr));
}

هر ستون حداقل ۱۶rem است و تا جایی که جا باشد ستون اضافه می‌شود.

نواحی نام‌دار

.page{
  display:grid;
  grid-template-columns:16rem 1fr;
  grid-template-areas:
    "header header"
    "side   main"
    "footer footer";
  min-height:100vh;
}
.page > header{ grid-area:header; }
.page > aside{ grid-area:side; }
.page > main{ grid-area:main; }
.page > footer{ grid-area:footer; }

انتخاب بین Flex و Grid

  • Flex: ردیف یا ستون یک‌بعدی، مثل نوار منو.
  • Grid: شبکه دوبعدی، مثل لایه‌بندی کل صفحه.
  • می‌توانی داخل خانه‌های Grid از Flex استفاده کنی.
